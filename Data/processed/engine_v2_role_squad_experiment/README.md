# Engine V2 role-trajectory and squad-competition experiment

This development diagnostic tests whether strictly pre-signing role level,
role trajectory, on-field same-position competition, and positional
value/incoming competition add signal beyond the compact Phase-4 baseline.
Each block is tested separately, followed by one predeclared combined block.

Every candidate is paired with a baseline retrained on identical rows.
Unavailable and unsupported rows remain visible as operational refusals. The
2024+ final holdout was not opened; no model was serialized or deployed.
