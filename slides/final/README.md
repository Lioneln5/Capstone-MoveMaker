# Final presentation

[`MoveMaker_Final_Presentation.html`](MoveMaker_Final_Presentation.html) is the
self-contained, 20-slide presentation submitted by Data Group 6 on
August 19, 2026. Download the file and open it in a modern browser; use the
on-screen controls or the arrow keys to navigate.

The deck embeds its fonts, images, charts, and presentation runtime. The live
demo link intentionally targets `http://127.0.0.1:8000/` and works only when
the MoveMaker API is running locally as described in the root README. The
presentation remains usable without the API; only the live application link is
local.

Superseded PowerPoint/PDF drafts, mock-presentation scripts, render-inspection
files, and intermediate chart exports are intentionally excluded from Git.
They do not represent the final submitted narrative or the current production
model state.
